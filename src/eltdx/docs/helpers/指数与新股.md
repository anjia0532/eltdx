# 指数与新股

查询指数成份股、跟踪某个指数的全部产品，以及近期新股列表。这三个能力走 7615 F10
通道，不需要 7709 连接，也不需要启动通达信客户端。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.index_members(code)` / `client.helpers.index_etfs(code)` / `client.helpers.ipo_calendar()` |
| 返回 | `IndexMemberTable` / `IndexTrackingTable` / `IpoCalendar` |
| 数据来源 | `7615` TQLEX（`CWServ.skef10_zs_*` / `CWServ.skef10_dpzx_xgfx`） |
| 缓存 | 按代码缓存，`refresh=True` 强制刷新；`client.clear_cache()` 清空 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    members = client.helpers.index_members("000905")     # 中证 500 成份股
    products = client.helpers.index_etfs("000300")       # 跟踪沪深 300 的产品
    ipos = client.helpers.ipo_calendar()                 # 近期新股

print(members.total, members.count)
print(members.full_codes[:5])
print(len(products.etfs), "只场内 ETF /", products.count, "只全部产品")
print(ipos.rows[0].apply_date, ipos.rows[0].full_code, ipos.rows[0].name, ipos.rows[0].issue_price)
```

`index_members` 与 `index_etfs` 接受 6 位指数代码或带市场前缀（`000905` / `sh000300`），
实测 `000300` 成份 300 只、跟踪产品 299 只，`000905` 成份 500 只，`399006` 成份 100 只，
`000001` 成份 2229 只。新股列表约 50 行，覆盖沪深北三市，按日期倒序。

| 角色 | 调用 |
| --- | --- |
| 指数成份股 | `client.helpers.index_members(code)` |
| 跟踪产品 | `client.helpers.index_etfs(code)` |
| 近期新股 | `client.helpers.ipo_calendar()` |

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 指数代码，6 位数字或带市场前缀 |
| `refresh` | 跳过缓存重新拉取，默认 `False` |

## 返回字段

`IndexMemberTable`：`index_code`、`total`（服务端报告的样本总数）、`rows`；
属性 `count` / `codes` / `full_codes`。行模型 `IndexMember` 字段：
`code`、`name`、`market_id`、`join_date`（纳入日期）、`market`、`full_code`。

`IndexTrackingTable`：`index_code`、`total`、`rows`；属性 `count` / `etfs`
（按代码号段 51/56/58/15/159/16 粗筛的场内 ETF）。行模型 `IndexTrackingProduct` 字段：
`code`、`name`、`scale_yuan`（基金规模，元）、`change_pct`（涨跌幅 %）、
`amount_yuan`（成交额，元）、`inception_date`（成立日期）、`manager`（基金经理）、
`company`（基金公司）、`nav`（单位净值）、`fee_rate_pct`（管理费率 %）、`market`、`full_code`。

`IpoCalendar`：`rows`；属性 `count` / `full_codes`。行模型 `IpoEntry` 字段：
`apply_date`（申购日）、`code`、`name`、`issue_price`（发行价，元）、
`raise_amount`（实际募资总额，元，另有 `raise_amount_yi` 亿元属性）、
`issue_pe`、`extra_pct`、`apply_limit`（后三者服务端未标注，为推断字段）、
`market`、`full_code`。

!!! warning "权重与推断字段"

    - **成份权重服务端不返回**：`IndexMemberTable` 只有成份清单，没有权重。
      需要指数权重请用通达信客户端（TQ `get_index_weight`）。
    - `IpoEntry` 的 `issue_pe` / `extra_pct` / `apply_limit` 与
      `IndexTrackingProduct` 的 `market_id` 均来自未标注列，已按语义命名，
      **生产使用前请用行内 `raw` 复核**。

## 与 TQ 的对应关系

| eltdx | 通达信 TQ |
| --- | --- |
| `helpers.index_members(code)` | `get_index_stocks` / `get_zzgz_stocklist` |
| `helpers.index_etfs(code)` | `get_trackzs_etf_info`（反向：给定指数找产品） |
| `helpers.ipo_calendar()` | `get_ipo_info` |
