# v3.3.1

发布日期：2026-10-30。

本版本汇总 v3.3.0 之后合并的 F10、资金流、宏观指标、行情修复和资源释放改进，并补齐 EX / MAC / MAC-EX 单接口文档。

## 主要变化

- **7615 F10 分区查询扩展**：完善 `shareholders`、`capital_structure`、`business_report`、`industry_analysis`、`trading_report`、`fund_report`、`market_report`、`latest_news` 的 `section` 分派；覆盖股东、股本、经营、行业、交易、基金 / ETF、板块与指数等资料。
- **指数与扩展市场资料**：新增指数成份股、指数跟踪产品、新股日历、板块成份分红资料及指数估值快照；补充指数两融日序列、投资者统计、港美股 / 外盘 F10 和个股总评、深度分析封装。
- **资金流历史**：`client.money_flow.history()` 接入 7615 TQLEX 数据，支持 3 / 5 / 10 / 20 / 60 日窗口，返回结构化历史模型；与 7709 `client.money_flow.daily()` 的接口及口径分别说明。
- **行情订阅**：`client.quotes.subscribe()` 提供基于现有 `0x0547` 增量刷新与推送队列的同步订阅封装，可逐轮派发或阻塞运行，并支持停止和错误回调。
- **宏观指标**：`MacExClient.macro_indicators()`、`macro_quotes()`、`macro_kline()` 接入扩展市场 38。支持枚举真实代码、读取最新报告值及历史序列；例如完整代码 `1_GDP`。宏观数据日期为报告期标签，不视为发布时间。
- **MCP 字段说明**：F10 结果新增按 Entry 和请求作用域区分的 `field_labels`、`unmapped_fields`，保留原始行数据；同步新增 F10 相关工具和调用契约。
- **完整扩展接口文档**：新增 47 个业务方法单页、3 个连接管理页及索引 / 枚举位图 / 返回模型参考，共 53 份文档。接口目录增至 121 项，网站与安装包文档同步。

## 修复内容

- 修复可转债当日 / 历史成交价格、`price_milli`、K 线 `volume_lots` 及裸代码市场识别。覆盖沪市 `110/113/118`、深市 `123/127/128` 号段；显式市场前缀仍优先。例如原始成交价格 `126901` 应解为 `126.901` 元。
- 完整 K 线聚合按旧页到新页组织结果，保留各页内部的记录顺序；完整 K 线和成交聚合清空 `raw_payload`，避免把首个响应误当成全量原文。单页接口仍可保留原始响应。
- 打断 `TdxClient` 与子服务 / Helper / 回调之间的引用环，改善客户端释放后底层线程延迟回收的问题；扩展行情探活早退时关闭在途连接并等待探活任务退出。
- 修正 `fund_report`、`market_report` 部分分区的日期 / 分类参数位置，改善有接口但返回空数据的情况。
- 修复订阅轮询异常处理中断循环的问题：提供 `on_error` 时将异常交给回调并继续后续轮询；回调自身异常按文档约定传播。
- 同步安装包 smoke、MCP / CLI 工具契约及测试清单，保留可转债回归测试。
- 修正文档中的 EX 自动分页、MAC-EX 排序参数、默认值和时间精度说明。已实现的 MAC `0x122F` 带服务器秒字段，可返回多笔聚合记录；标准 `0x0FC5/0x0FC6` 的分钟字段不代表整个库只有分钟精度。

## 兼容性与迁移

- 保持 Python 3.10+；基础安装仍没有第三方运行时依赖。MCP / HTTP 功能继续通过可选依赖安装。
- **保留客户端引用**：引用环修复后，子服务不再替客户端延长生命周期。请先绑定 `client = TdxClient(...)`，或用 `with TdxClient() as client:`；直接从临时客户端取子服务再调用可能抛 `ReferenceError`。
- **移除可转债补偿**：若业务代码曾手动将成交价格除以 10、将 K 线手数乘以 100，应移除该补偿，避免重复修正。
- **全量原文**：完整分页结果的 `raw_payload` 为空；需要逐页原文时使用单页接口手动分页，并保存各次响应。
- **数据语义**：宏观序列不是股票成交行情；MAC 秒级成交可聚合多笔，不等于交易所 Level-2 逐笔。扩展市场命令是否可用、历史留存及数量单位仍取决于具体主机和品种，详见接口单页。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.3.1"
```

需要可选功能时：

```bash
python -m pip install --upgrade "eltdx[mcp,http]==3.3.1"
```
