# v3.3.2.1

发布日期：2026-11-04。

本仓库是 `electkismet/eltdx` 的 fork 发布线，版本标识遵循「上游版本 + .x」规则：`v3.3.2.1` 对齐上游 `v3.3.2`（含 upstream/main 至 `f3bfa3d` 的文档更新）。Python / Rust 包版本仍为 `3.3.2`——Cargo 的 semver 只接受三段版本号，`3.3.2.1` 仅用于 Git tag、GitHub Release 与文档记录，不是可安装的 Python 版本号。

## 主要变化

- **与上游对齐**：fork 树内容回到上游 `v3.3.2`，移除 3.4.x 自发版说明与本地研究资产（`scripts/f10_*`、`tmp_f10/`），补回上游的 EX / MAC / MAC-EX 完整 API 文档、批量缺失处理与可转债数据契约修复。
- **保留唯一 CI 差异**：PyPI 发布失败不阻断 GitHub Release（`publish.yml` 中 `continue-on-error` 与 release job 的显式 `if` 门）。
- **版本命名**：fork 发布标识改为「上游版本 + .x」，首个标识为 `v3.3.2.1`；发版校验脚本同步支持四位 tag。
- **修复 issue #28**：扩展行情连接补发 92B `ExSetupCmd1` 会话握手包并读走应答，探活命令改用市场列表枚举。

## 修复内容

- `ExTdxConnection.connect()` 在 TCP 建连后发送固定 92B 握手包，并完整读走响应头与响应体，避免握手帧被下一条业务命令误解析（旧实现会超时、连接重置或静默返回空结果）。
- `default_probe_command()` 从 `0x23f5`（枚举）改为 `0x23f4`（市场列表），使 DATA 级供数主站在完成握手后能被探活正确识别。
- 新增 `send_setup` 开关，供 MAC-EX 等另有 `0x2454` 登录流程的会话按需关闭握手。

## 兼容性与迁移

- 包版本仍为 `3.3.2`：`pip` 安装与依赖约束不变，`3.3.2.1` 是发布标识。
- 默认 `send_setup=True`；连接 MAC-EX 会话台时若另有登录流程，可显式设为 `False`。
- 探活命令改为市场列表后，仅应答 `0x23f5` 的目录级主站不再被判为健康，属预期行为。

## 升级

本发布标识对应上游 `v3.3.2` 代码基线，安装包版本不变：

```bash
python -m pip install --upgrade "eltdx==3.3.2"
```
