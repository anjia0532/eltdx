# v3.4.2

## 主要变化

本版修掉 `v3.4.0` 引入的 7615 F10 分区的几处参数缺陷，并补齐相关文档。全部改动都围绕
`client.f10.fund_report()` 与 `client.f10.market_report()` 的 `section` 分派。

- **`market_report()` 免代码分区可用**：`market_new_shares` / `market_capital` 现在可以省略 `code`
  （或传空串 `""`）；其余分区传空串仍照原样抛 `ProtocolError`。
- **`fund_report(section="scale_history")` 不再报错**：默认 `arg` 由 `"1"` 改为 `"0"`，返回报告期
  规模份额序列（`510300` 50 行）。
- **`fund_report(section="scale")` 返回完整表**：底层参数由 `["4", ...]`（只返回 `rq` 列）改为
  `["0", ...]`，与 `scale_history` 一致。
- **`fund_report` 报告期分区自动取最新报告期**：`industry_allocation` / `bond_allocation` /
  `futures_allocation` 未传 `date` 时先取 `*bgq` 报告期列表再查明细（与客户端一致）。
- **CLI**：`eltdx f10 market` 允许省略 `CODE`（配合 `--section market_new_shares` / `market_capital`）。

## 修复内容

- **`market_report()` 免代码分区**：`market_new_shares` / `market_capital` 的分区表本来不使用 `code`，
  但方法无条件执行 `_code6(code)`，传空串会抛 `ProtocolError: invalid code: ''`。现按白名单
  （`_MARKET_REPORT_CODELESS_SECTIONS`）跳过校验；非白名单分区传空串依旧抛错，避免静默发出空代码请求。
- **`fund_report(section="scale_history")` 默认参数报错**：实测 `{"Params": ["1", code, "", ""]}`
  恒返回 `ErrorCode=-1005`（客户端那条 `["1", stock, transSort, value]` 需要排序参数），
  而 `["0", code, "", ""]` 返回报告期规模份额序列（`rq` / `qmjzc` 期末净资产 / `T005` 期末总份额 /
  `bdl` / `jzcbdl` 变动率）。
- **`fund_report(section="scale")` 返回退化表**：`["4", ...]` 对任意基金只返回 `rq` 列、无数据；
  已改为 `["0", ...]`。
- **`fund_report` 报告期分区**：`industry_allocation` / `bond_allocation` / `futures_allocation`
  不传 `date` 时恒返回 0 行；现先用 `hyfbbgq` / `zczqbgq` / `ccqhmxbgq` 取最新报告期再查明细。
- **CLI**：`eltdx f10 market` 之前强制要求一个 `CODE`；现对免代码分区允许省略。

## 文档

- `F10-基金与ETF.md` / `F10-板块与指数.md` / `API_REFERENCE.md` / `METHOD_REFERENCE.md` / `CLI.md`
  同步上述行为。
- `F10-基金与ETF.md` 明确多结果集语义：**`response.rows` 只给第一张表**，`etf` / `margin` 的
  `table0` 是「是否 ETF」门控、数据在 `response.tables[1]`。
- `7709-K线周期线.md` 新增「分钟 K 的可取深度（实测）」：`1m` ≈ 23520 根、`5m` ≈ 23904 根，
  分钟线在 7709 上最多约 2.3～2.4 万根，受主站保留窗口限制（不是协议限制）。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.4.2"
```

- 从 `v3.4.1` 升级**无破坏性变更**：只修正 `fund_report` / `market_report` 的部分 `section` 参数，
  其余 Python API 与协议实现不变。
- 若之前为 `market_new_shares` / `market_capital` 传了占位 `code`，可继续传，也可省略。
- 仍然提供各平台预编译 wheel（abi3，覆盖 Python 3.10–3.14），安装无需本地 Rust 工具链。
