# F10-首页要闻

版本说明：PR #31 新增，自 v3.3.2 起可用。

查询全市场要闻速递、滚动资讯、今日焦点等首页资讯流，通过 7615 HTTP Entry 调用。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.f10.market_news(tab=3, *, page=1, page_size=50)` |
| Entry | `CWServ.tdxi_zxxwsy` |
| Params | `[str(tab), str(page), str(page_size)]` |
| 返回 | `F10Response` |

## 参数

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `tab` | `3` | `NewsHomeTab` 或整数；1 滚动、2 今日焦点、3 要闻、4 正面、5 负面、6 精华、7 最新提示、9 机构调研 |
| `page` | `1` | 页码，从 1 开始；一次调用仅取一页 |
| `page_size` | `50` | 每页条数，服务端决定实际返回数量 |

`tab=8` 对应前端停用栏目，不列入受支持标签。分页参数按原值交给服务端，无自动翻页。

## 示例

```python
from eltdx.f10 import F10Client, NewsHomeTab, extract_news_rows

client = F10Client()
response = client.market_news(NewsHomeTab.HEADLINES, page=1, page_size=20)
for row in extract_news_rows(response):
    print(row["Issue_date"], row["Title"], row.get("Url"))
```

## 返回与空数据

返回 `F10Response`，新闻行位于第二个结果集 `result_sets[1].rows`，建议使用 `extract_news_rows(response)` 提取为 `list[dict]`。没有第二个结果集时，提取函数返回空列表；这与 HTTP 错误、Entry 错误是不同情况，检查响应的 `error_code` / `ok` 和 `raw`。

| 字段 | 含义 |
| --- | --- |
| `Title` | 新闻标题 |
| `Issue_date` | 发布时间，保留服务端字符串 |
| `Summary` | 摘要 |
| `rec_id` | 记录 ID |
| `Info_Src` | 来源 |
| `Url` | 原文链接 |
| `AttachFile` | 附件 |
| `bProc` | 研报类标记，保留服务端值 |

全市场资讯与个股 `company_news()` / `news()` 分属不同接口。频道、标签完整列表及原始 Entry 调用见 [市场资讯总览](F10-市场资讯.md)。

## CLI / MCP / HTTP

```bash
eltdx f10 market-news --tab 3 --page-size 20
```

MCP：`eltdx_market_news(tab=3, page_size=20)`。

HTTP / WebSocket 通用 RPC：

```json
{"id": 1, "method": "f10.market_news", "params": {"tab": 3, "page": 1, "page_size": 20}}
```
