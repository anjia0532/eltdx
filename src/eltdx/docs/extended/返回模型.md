# EX / MAC / MAC-EX 返回模型

模型为 Python dataclass（动态报价字段为 dict），不依赖 pandas。下表列出当前实际字段；同名字段在不同协议中的单位不保证相同。示例 JSON 序列化可用 eltdx.to_jsonable，日期/时间应保留所选市场和请求日期。

## MacQuoteField

| 字段 | Python 类型 | 含义与口径 |
| --- | --- | --- |
| `market` | `int` | 市场编号，按当前协议的市场表解释。 |
| `code` | `str` | 证券/合约代码字符串，保留前导零。 |
| `name` | `str` | 名称文本；GoodsItem 的特殊语义见该模型。 |
| `fields` | `dict[str, Any]` | 按请求位图解析的动态字典；键名为 FieldBit.field_name。 |

## MacTransaction

| 字段 | Python 类型 | 含义与口径 |
