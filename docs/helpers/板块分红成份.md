# 板块分红成份

按板块代码读取成份股的**分红记录**（分红方案、进度、公告 / 登记 / 除权日、报告期）。
走 7615 F10 通道，不需要 7709 连接，也不需要启动通达信客户端。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.helpers.board_members(board_code, refresh=False)` |
| 返回 | `BoardMemberTable` |
| 数据来源 | `7615` TQLEX（`CWServ.skef10_bk_getinfo`，section `board_members`） |
| 缓存 | 按板块代码缓存，`refresh=True` 强制刷新；`client.clear_cache()` 清空 |

## 示例

```python
from eltdx import TdxClient

with TdxClient(timeout=3) as client:
    board = client.helpers.board_members("880472")   # 证券板块

print(board.total, "条记录 /", len(board.stocks), "只证券")
print(board.full_codes[:5])
print(board.rows[0].code, board.rows[0].name, board.rows[0].dividend_plan)
```

实测 `880472`（证券板块）共 **67 条分红记录、44 只证券**（21 只同时有中报和年报
两条记录），按公告日期降序。板块代码接受 6 位数字或带市场前缀
（`880472` / `sh880472`）。

| 项目 | 内容 |
| --- | --- |
| 板块分红成份 | `client.helpers.board_members(board_code)` |

## 参数

| 参数 | 含义 |
| --- | --- |
| `code` | 板块代码，6 位数字或带市场前缀 |
| `refresh` | 跳过缓存重新拉取，默认 `False` |

底层 `client.f10.board_members(code, *, all_pages=True, page_size=100, max_pages=50)`
另支持 `all_pages=False`（只取第一页）与 `page_size` / `max_pages`。

## 返回字段

`BoardMemberTable`：`board_code`、`total`（服务端报告的**记录总数**，不是证券
只数）、`rows`；属性 `count` / `stocks`（去重后的证券代码）/ `full_codes`。

行模型 `BoardMember` 字段：`code`、`name`、`market_id`、`dividend_plan`
（分红方案）、`progress`（进度）、`announce_date`、`record_date`、`ex_date`、
`report_period`（报告期）、`market`、`full_code`、`raw`（服务端原始行）。

!!! warning "一行 = 一条分红记录，不是一只股票"

    - 同一证券的中报 / 年报分红各占一行，`rows` 里同一代码会出现多次；
      `total` 是记录总数。**只要证券清单请用 `.stocks` / `.full_codes`**，
      不要对 `rows` 按代码去重后当成份股用。
    - `N005` / `N006` / `N007` 服务端未标注含义，按 A 股分红实施流程命名为
      `announce_date` / `record_date` / `ex_date`，**均为推断字段**，
      生产使用前请用行内 `raw` 复核。

!!! warning "服务端翻页对同日记录不稳定"

    排序按公告日期降序，但**同日记录的服务端次序在两次请求间会变**（实测同一
    `page=2` 连续请求两次结果不同，出现跨页重复行）。因此封装按**记录身份**
    （代码 + 方案 + 三个日期 + 报告期）去重，而不是按代码去重。想完全绕开翻页，
    用 `page_size=100`（默认值）单页取全。
