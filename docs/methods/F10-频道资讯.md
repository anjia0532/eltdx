# F10-频道资讯

版本说明：PR #31 新增，自 v3.3.2 起可用。

按频道号读取财经、股票、新股、港美股、基金、期货、理财、外汇、债券和期权资讯。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.f10.channel_news(channel, *, page=1, page_size=50, query1="1", keyword="")` |
| Entry | `CWServ.tdxi_zxxwnews` |
| Params | `[str(query1), str(channel), str(page), str(page_size), keyword]` |
| 返回 | `F10Response` |

## 参数

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `channel` | 必填 | `NewsChannel` 或整数频道号，例如 201 财经要闻；用 [资讯频道列表](F10-资讯频道列表.md) 枚举 |
| `page` | `1` | 页码，从 1 开始，一次调用取一页 |
| `page_size` | `50` | 每页请求条数，实际条数由服务端决定 |
| `query1` | `"1"` | 原始查询模式，通常保留默认值 |
| `keyword` | `""` | 透传关键词，筛选效果取决于服务端栏目 |

## 示例

```python
from eltdx.f10 import F10Client, NewsChannel, extract_news_rows

client = F10Client()
response = client.channel_news(NewsChannel.FINANCE_HEADLINES, page=2, page_size=20)
for row in extract_news_rows(response):
    print(row["Issue_date"], row["Title"])
```

## 返回与空数据

返回 `F10Response`，新闻行位于第二个结果集 `result_sets[1].rows`，建议使用 `extract_news_rows(response)` 提取为 `list[dict]`。没有第二个结果集时，提取函数返回空列表；这与 HTTP 错误、Entry 错误是不同情况，检查响应的 `error_code` / `ok` 和 `raw`。

| 字段 | 含义 |
| --- | --- |
| `Title` | 新闻标题 |
| `Issue_date` | 发布时间，保留服务端字符串 |
| `Summary` | 摘要 |
| `rec_id` | 记录 ID |
| `Info_Src` | 来源 |
| `Url` | 原文链接 |
| `AttachFile` | 附件 |
| `bProc` | 研报类标记，保留服务端值 |

全市场资讯与个股 `company_news()` / `news()` 分属不同接口。频道、标签完整列表及原始 Entry 调用见 [市场资讯总览](F10-市场资讯.md)。

`1011` 互联网金融栏目实测可能返回空列表，空结果不代表协议损坏。产经栏目使用另一 Entry `CWServ.tdxi_zxtzckcontent`，尚未包含在此频道枚举中。
