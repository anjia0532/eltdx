# F10-资讯频道列表

版本说明：PR #31 新增，自 v3.3.2 起可用。

静态列出资讯频道号和中文名称，供 [频道资讯](F10-频道资讯.md) 使用。

| 项目 | 内容 |
| --- | --- |
| 调用 | `client.f10.news_channels()` |
| 参数 | 无 |
| 返回 | `list[tuple[int, str]]`，按频道号升序排列，当前 84 项 |
| 网络 / Entry | 无；读取本地 `NEWS_CHANNEL_LABELS` 常量 |

## 示例

```python
from eltdx.f10 import F10Client, NEWS_CHANNEL_GROUPS

client = F10Client()
channels = client.news_channels()
for channel_id, name in channels:
    print(channel_id, name)
# (200, "最新"), (201, "财经要闻"), ...
```

元组的第一项是频道号，第二项是栏目名。多个频道的名称可能都是“最新”，应使用频道号作为标识。分组常量 `NEWS_CHANNEL_GROUPS`、枚举 `NewsChannel` 和 `channel_name()` 也可直接使用；完整映射见 [市场资讯总览](F10-市场资讯.md)。

此列表不会联网刷新。列入枚举表示存在该频道定义，不保证服务器当前有数据；客户端内置枚举与网站调整之间可能存在时间差。返回 JSON 时，每个元组序列化为两元素数组。

## CLI / MCP / HTTP

```bash
eltdx f10 news-channels
```

MCP：`eltdx_news_channels()`。

```json
{"id": 3, "method": "f10.news_channels", "params": {}}
```
