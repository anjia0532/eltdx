# v3.4.5

本版合并了原计划的 v3.4.4 / v3.4.5 两轮未发布改动，一次发车：新增**指数成份股 /
跟踪产品 / 新股 / 订阅推送 / 板块分红成份**能力，把资金流历史的行序统一成
「最新在前」，并修正「美股需要回客户端」的错误结论（美股一直在扩展行情里）。

## 主要变化

- **指数成份股清单**：新增 `f10.index_members(code)` 与 `helpers.index_members(code)`，
  走 7615 Entry `CWServ.skef10_zs_cfgsj_cfgjcsj`，自动翻页，返回语义化的
  `IndexMemberTable`（`code` / `name` / `join_date` / `market` / `full_code`）。
  这是通达信 TQ `get_index_stocks` / `get_zzgz_stocklist` 的等价能力。
  实测 `000300` 300 只、`000905` 500 只、`399006` 100 只、`000001` 2229 只。
- **指数跟踪产品**：新增 `f10.index_tracking_products(code)` 与 `helpers.index_etfs(code)`，
  走 `CWServ.skef10_zs_jbxx_gzbd`，返回 `IndexTrackingTable`（规模、涨跌幅、成交额、
  成立日期、基金经理、基金公司、单位净值、管理费率），`.etfs` 可按代码号段粗筛场内 ETF。
  与 TQ `get_trackzs_etf_info` 方向相反：给定指数找产品。实测 `000300` 返回 299 只。
- **近期新股列表**：新增 `f10.ipo_calendar()` 与 `helpers.ipo_calendar()`，走
  `CWServ.skef10_dpzx_xgfx`（参数 `002`），返回 `IpoCalendar`（申购日、代码、名称、
  发行价、募资总额）。这是 TQ `get_ipo_info` 的等价能力。实测约 50 行，覆盖沪深北三市。
- **订阅式实时行情回调**：新增 `quotes.subscribe(codes, callback)`（别名
  `subscribe_hq`），对齐 TQ `subscribe_hq` 心智模型——`refresh` 激活 +
  `poll_push` 轮询，每帧推送按代码派发 `QuoteRefreshRecord`。支持 `run()` 阻塞循环、
  `run_once()` 单轮、`stop()` 跨线程停止、`on_error` 兜底、`reactivate_interval` 续期。
- **板块分红成份**：新增 `f10.board_members(code)` / `helpers.board_members(code)`，
  走 7615 F10 的 `CWServ.skef10_bk_getinfo`（`board_members` 分区），返回
  `BoardMemberTable`。给出成份股的分红方案、进度、公告 / 登记 / 除权日和报告期，
  按记录身份去重自动翻页（`page_size` 默认 100，单页取全）。
  实测 `880472`（证券板块）共 **67 条分红记录、44 只证券**。
  与 `helpers.board_member_quotes()`（7709 实时行情）互补。
  新增导出 `BoardMember` / `BoardMemberTable`（`eltdx` 与 `eltdx.f10`）。
- **`market_report()` 新增 3 个 section**：`index_members`（指数成份股清单）、
  `index_etfs`（跟踪该指数的产品）、**`index_valuation`（指数估值快照）**，
  加上 `market_new_shares` 的语义别名 `ipo_calendar`。分区数 22 → **26**。
- **指数估值快照**：`market_report(code, "index_valuation")`，走
  `CWServ.skef10_zs_jbxx_gzxx`（`["001", code, "", ""]`），返回市盈率TTM / LYR、
  市净率MRQ / 加权、市销率TTM / LYR、市现率TTM / LYR、股息率（%）、净资产收益率
  与报告期。实测 `000300` 市盈率TTM 13.01 / 市净率MRQ 1.27 / 股息率 2.94%、
  `000001` 15.10 / 1.29 / 2.61%、`399001` 26.65 / 2.36 / 1.79%。
  个股估值历史与百分位走 `f10.valuation(code, req_id="200191")`。
- **CLI 新命令**：`eltdx index members <code>` / `eltdx index etfs <code>` /
  `eltdx ipo`，支持 `--etf-only`、`--first-page`、`--page-size` 与 `-o table/json`；
  另加 `eltdx f10 board-members <code>`（板块分红成份，自动翻页去重）。
- **新增文档**：`docs/TDX_TQ_CAPABILITY_MAP.md` 对照通达信 TQ 逐项列出覆盖情况。

## 修复内容

- **美股能力结论纠错**：能力矩阵此前把「美股行情」列为必须回到通达信客户端的
  缺口，实测证明该结论错误——外盘股票就在扩展行情里：`ExMarket.US_STOCK = 74`
  （美股 **13409** 只）、`GE_STOCK = 73`（德股 40 只）、`SG_STOCK = 78`
  （新加坡股 1392 只）。走 `MacExClient` 的 `instruments` / `goods_quotes` /
  `goods_kline` / `goods_tick_chart` / `goods_transaction` 全部可取数，
  枚举带中文名（`AAPL`=苹果、`NVDA`=英伟达），日 K / 分时 / 逐笔正常。
  能力矩阵改为覆盖项，用法与实测细节见 `docs/EXTENDED_MARKET.md`
  「外盘股票」节。
- **成份权重与推断字段的结论明确写入文档**：7615 成份股 Entry 只返回代码 / 名称 /
  纳入日期 / 市场标记，**不返回权重**（通达信客户端同样没有权重信息）；新股的
  `issue_pe` / `extra_pct` / `apply_limit` 来自服务端未标注列（`N004` / `N005` /
  `N007`），按语义命名，docstring 中明确标注为推断，提示用行内 `raw` 复核后再用于生产。
- **BREAKING · `money_flow.history` 行序统一为日期降序（最新在前）**：服务端原始
  回包是日期升序，此前原样返回，与文档声明的「`start=0` 为最新一条」矛盾，也与
  F10 其它日期序列（`ipo_calendar` / `market_margin_summary` / `index_members`）
  方向相反。现在客户端统一反转，与 `money_flow.daily()`（`records[0]` 即最新
  交易日）口径一致，`start` / `count`（距最新偏移）的语义随之成立。
- **`board_members` 分区同日记录翻页不稳定**：服务端对公告日期相同的记录，两次
  请求的次序不同，跨页会出现重复行（服务端行为）。封装层按**记录身份**
  （代码 + 方案 + 三个日期 + 报告期）去重规避——不是按代码去重，按代码去重会丢掉
  合法的多条分红记录。文档已标注该限制。

## 升级

- **BREAKING**：`client.money_flow.history(...)` 的 `rows` 从「服务端原始升序
  （最旧在前）」变为「日期降序（最新在前）」。依赖 `rows[0]` 是最旧一条、
  或按 `start` / `count` 从最旧方向切片的下游需要相应调整；想要「最近 N 日」
  现在是 `start=0, count=N`。
- 新增 `BoardMember` 的 `announce_date` / `record_date` / `ex_date` 三列服务端
  未标注含义，按 A 股分红实施流程命名，**属推断字段**，生产使用前请用行内
  `raw` 复核（docstring 与 `docs/methods/F10-板块与指数.md` 均已标注）。
- 除上述一条外无其它破坏性变更：指数 / 新股 / 订阅 / 分红均为新增方法与 section，
  不改既有签名和返回结构。
- `helpers` 新增能力默认按代码缓存，与既有 helper 一致；`client.clear_cache()` 可清空。
- 仍然提供各平台预编译 wheel（abi3，覆盖 Python 3.10–3.14），安装无需本地 Rust 工具链。

```bash
python -m pip install --upgrade "eltdx==3.4.5"
```
