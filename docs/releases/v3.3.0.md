# v3.3.0

## 主要变化

- 新增扩展行情 `eltdx.ex`（7727），支持市场和标的查询、报价、K 线、分时及成交数据。
- 新增 `eltdx.mac`（7615），包含同步客户端、编解码、价格规则与复权支持。
- 新增 `eltdx.offline`，读写本地日线和分钟线文件，并读取板块、行业、历史财务及 GBBQ 文件。
- 新增专业财报 `eltdx.financial`，补齐 7709 公司信息目录、正文和板块元信息命令。
- 新增 `eltdx` 命令行工具及 `python -m eltdx` 入口。
- K 线查询新增 `bar_time` 参数，可选择起点或右端点时间；默认保留原有时间语义，日线及以上不受影响。
- 新增全市场统计和当日资金流辅助方法，补充接口说明及从 easy-tdx 迁移指南。

## 修复内容

- 修复 MAC K 线请求帧、港股本地日线成交额解释及本地行情文件残尾读取问题。
- 补齐沪市 `5xxxxx` 和北交所 `4xxxxx` 代码识别。
- 主机省略端口时自动补齐默认端口，修复裸 IPv6 地址解析。
- 资金流为空时有界探测其他主站；所有主站都为空时仍返回空数据。
- 扩展市场 CLI 默认使用内置市场表，显式指定 `--probe-server` 才探测服务器，避免无效等待。
- 修正文档链接，并保持安装包内文档与文档站内容一致。

## 兼容性

从 `v3.2.3` 升级保留原有 API 默认行为。新增参数均提供默认值。
历史扩展 K 线范围查询无法确定周期时长，传入 `bar_time="end"` 时会显式报错。
各在线接口的数据覆盖范围取决于服务器支持情况。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.3.0"
```
