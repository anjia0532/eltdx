# v3.3.2.2

发布日期：2026-11-06。

本发布标识延续「上游版本 + .x」规则，对齐上游 `v3.3.2`（`f3bfa3d`）。Python / Rust 包版本仍为 `3.3.2`，`3.3.2.2` 仅用于 Git tag、GitHub Release 与文档记录。

## 主要变化

- **修复 CI**：`crates/eltdx-runtime/src/pin.rs` 按 rustfmt 1.89.0 规范化，`cargo +1.89.0 fmt --check` 恢复通过（此前该检查在上游树对齐后失败）。
- **MAC-EX 探活入口对齐**：`MacExClient.ping_all()` 与 `from_best_host()` 改用 `mac_ex_mode=True` + `MacExLoginCmd`，与 `connect()` 的会话流程一致，避免把 MAC-EX 主站误判为不可用。

## 修复内容

- `ping_ex_host` / `ping_ex_all` 新增 `mac_ex_mode` 与 `command_factory` 关键字参数并透传给 `probe_ex_host(s)`（默认值不变，向后兼容）。
- 新增两条回归测试覆盖这两个高层探活入口。

## 实测

- 修复后 MAC-EX 探活：`MAC_EX_HOSTS` 2 台 **2/2 应答**（100.29ms / 100.42ms）。
- 旧语义（`mac_ex_mode=False` + markets）：2 台 **0/2 全超时**，会被误判为不可用。
- 端到端：`from_best_host()` 选中 `121.37.232.167`，`goods_count()=110004`，`macro_indicators()=217` 个指标。

## 兼容性与迁移

- 包版本仍为 `3.3.2`：`pip` 安装与依赖约束不变，`3.3.2.2` 是发布标识。
- EX（非 MAC-EX）探活保持 `mac_ex_mode=False` + markets 不变。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.3.2"
```
