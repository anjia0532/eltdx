# v3.4.7

## 主要变化

本版把 F10 能力从 A 股扩展到**全部通达信页面家族**，并新增**宏观指标**（GDP / CPI /
PMI / M2 等 217 个）取数；同时同步 upstream PR #20 review 阶段的后半批修复。

- **扩展市场 F10（走 page2 网关，新增约 70 个语义化方法）**：美股 `mg_*`（17）、
  港股 `hk_*`（19）、新三板 `sb_*`（13）、债券 `bond_*` / `gz_*` / `qyz_*` / `gzhg_*` /
  `zczq_*` / `kjhz_*`（9 类债券全覆盖，26）、行业 `hy_*`（14）、期货 `qh_*`（9）。
- **个股总评与深度分析**：`stock_stage_gain` / `stock_main_funds` / `stock_industry_rank` /
  `stock_industry_pct_rank` / `stock_board_member_quotes` / `stock_valuation_percentile` /
  `stock_pepb_percentile` / `stock_history_trend` / `stock_finance_weights`。
- **宏观指标（`MacExClient`，市场 38）**：`macro_indicators()` / `macro_quotes()` /
  `macro_kline()`，217 个指标分 9 类（国民经济 / 物价 / 景气 / 对外经济 / 货币金融 /
  房地产与其他 / 证券市场 / 美国经济 / 利率与回购）；实测 GDP 1401879.25 亿元
  （年度序列 36 根）、CPI 100.9（月度 393 根）、PMI 50.1（月度 261 根）。
- **MCP 新增 8 个工具**（24 → 32）：`eltdx_f10_digest` / `eltdx_us_stock_f10` /
  `eltdx_hk_stock_f10` / `eltdx_bond_f10` / `eltdx_industry_f10` / `eltdx_stock_analysis` /
  `eltdx_macro_indicators` / `eltdx_macro_data`。
- **F10 字段中文映射扩展到美股 / 港股**：`f10/fields_mg_hk.py`（291 列），美股财报科目
  经 SEC 10-Q 逐项核对；财务报表继续按 `nhytype` 区分通用企业 / 银行 / 券商 / 保险模板。

## 同步 upstream PR #20 review 阶段修复

- **安全**：解压流 `eof` 完整性校验、板块文件路径穿越防护、财报 ZIP 炸弹限额与
  `read_dat_from_zip` 防重名绕过、索引偏移重复 / 总量超限、下载限额下推到传输层。
- **正确性**：涨跌停补 302 段且板块规则优先于 ST、秒级 K 线保留秒数、TickCharts `days`
  越界校验、0x5D / 0x5E / 0x88 / 0x8B 双语义位 canonical 修正、`connect()` 先建新连接再关
  旧连接、`find_lc1` 路径 `fzline`→`minline`、`SZ_BOND` 量系数 1.0→0.01、末条记录按长度
  向下对齐、资金流「已选主机为空时继续试其他候选主机」。

## 龙头矩阵实测发现的修复（20 行业龙头 × 30 方法 = 600 次调用）

- `theme_market` 漏 ReqId 200740 的 `zq_num`，`stock_stage_gain` 日线序列曾返回 0 行。
- `finance_diagnosis` 默认 `yynl` 已随页面改版下线（20/20 龙头全空）→ 默认 `zzyj`。
- `governance` 默认 `wgcl` 数据稀少 → 默认 `gljy`（关联交易）。
- `hk_market` 默认 section=1 对港股为空 → 默认 `3`（实测 3/4/6/7 有数据）。
- `hk_analyst_forecast` 空日期返回 0 行 → 默认近一年区间。
- 边界加固：`_us_code` 拒绝纯符号、`_hk_code` 拒绝混字母、期货 / 预测日期统一先 `strip`
  再去横线。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.4.7"
```

- 从 `v3.4.6` 升级**无破坏性变更**：A 股既有方法与返回结构不变；扩展家族为新增；
  仅 `finance_diagnosis` / `governance` / `hk_market` / `hk_analyst_forecast` 四个方法的
  **默认参数**改为有数据的取值（显式传参行为不变）。
- 宏观指标依赖扩展行情主站（`MacExClient`，7727），与 A 股主站（7709）相互独立。
- 仍然提供各平台预编译 wheel（abi3，覆盖 Python 3.10—3.14），安装无需本地 Rust 工具链。
