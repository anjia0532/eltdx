# v3.4.1

## 主要变化

本版是 **`v3.4.0` 的文档补齐版本**，代码行为不变；目的是把 `v3.3.0` / `v3.3.1` 已经发布、但从未写进 README 的几条数据通路补上，并修正若干过期计数。

- **README 补齐扩展行情等通路**：新增章节「扩展行情、场外基金、MAC 与本地行情文件」，覆盖
  `eltdx.ExTdxClient`（7727）、`eltdx.MacExClient` / `eltdx fund`（场外基金净值）、
  `eltdx.MacClient` / `eltdx mac`（MAC 协议）、`eltdx.offline` / `eltdx offline`（vipdoc 本地文件）
  和 `client.company_info`（`0x02cf` + `0x02d0` 文本型 F10），每类都给可运行示例与边界说明。
- **功能地图新增 14 行**：扩展行情、场外基金净值、MAC 协议、本地行情文件、公司信息文本 F10、
  交易日与日历、当日资金流向，并给 MCP 行补上 F10 中文字段标签（`field_labels` / `field_notes`）说明。
- **行情接口表补 3 行**：`0x02cf` 公司信息目录、`0x02d0` 公司信息正文、`0x02c5` 板块文件元数据；
  K 线章节补 `bar_time` 语义（`start` 为通达信原始口径、`end` 对齐 Tushare / 同花顺）。
- **命令行示例补全**：快速开始段落补 `eltdx ex` / `eltdx fund` / `eltdx mac` / `eltdx offline`；
  文档表补 [扩展行情](../EXTENDED_MARKET.md)、[本地文件](../OFFLINE.md)、
  [从 easy_tdx 迁移](../MIGRATION_FROM_EASY_TDX.md) 三个入口。

## 修复内容

- **README 的通路缺口**：此前 README 完全没有提到 7727 扩展行情、场外基金、MAC 协议、本地行情文件、
  公司信息文本 F10、`Market` 枚举和 `bar_time`，也没有 `ex` / `fund` / `mac` / `offline` 的任何命令行示例；
  已全部补齐，并给出实测结论（例如内置 16 台扩展行情主机中只有 1 台应答枚举命令 `0x23f5`、
  `ELTDX_EX_HOSTS` 可覆盖主机表而无需发版）。
- **过期计数**：README 的「21 个 7709 命令」改为 **25**；`ARCHITECTURE.md` 的 registry 命令计数
  由 22 改为 **25**（两处）——命令注册表与 `command_contracts.json` 实测均为 25，且 25 个命令全部
  标记为 `retry_safe`。
- **`v3.4.0` 变更记录补全**：补入此前遗漏的条目——`digest()` 方法、`industry_analysis` 的
  `comparable` / `comparable_profile`、`company_news(section="finance_review")`、
  `-o table / csv / jsonl` 展开 TQLEX 结果集、`eltdx f10 detail` 改为两个位置参数、
  `fund_report(section="finance")` 默认取表由 `cwzb` 改为 `zcfzb`。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.4.1"
```

- 从 `v3.4.0` 升级**无代码行为变化**：本版只改文档、README、变更记录与版本号（`Cargo.toml` /
  `Cargo.lock` / `interface-catalog-data.js` / 版本断言），Python API 与协议实现与 `v3.4.0` 完全一致。
- 如果此前按 README 组织过调用（例如用 `client.f10.*` 与 `client.money_flow.history()`），
  无需任何改动；扩展行情 / MAC / 本地文件是独立客户端，见 README 的
  「扩展行情、场外基金、MAC 与本地行情文件」一节。
- 仍然提供各平台预编译 wheel（abi3，覆盖 Python 3.10–3.14），安装无需本地 Rust 工具链。
