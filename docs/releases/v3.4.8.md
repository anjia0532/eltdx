# v3.4.8

## 主要变化

新增「市场资讯」模块，直接对接通达信 7615 资讯网关（`CWServ.tdxi_zxxwsy` /
`CWServ.tdxi_zxxwnews`），可获取全市场「要闻速递 / 滚动资讯 / 今日焦点 …」以及
11 个频道组、共 84 个栏目资讯，并打通 Python / CLI / MCP / HTTP 四种入口。

- **`F10Client` 新方法**：`market_news(tab, page, page_size)`、`channel_news(channel, page, page_size)`、
  `news_channels()`。
- **枚举与工具**：`eltdx.f10.news` 提供 `NewsHomeTab`（首页 8 个要闻流）、`NewsChannel`（84 个频道号）、
  `NEWS_CHANNEL_LABELS` / `NEWS_CHANNEL_GROUPS` / `channel_name()` / `home_tab_name()` /
  `extract_news_rows()`。
- **CLI**：`eltdx f10 market-news | channel-news | news-channels`（`--tab` / `--channel`）。
- **MCP**：新增 `eltdx_market_news` / `eltdx_channel_news` / `eltdx_news_channels`（工具 32 → 35）。
- **HTTP 网关**：`f10.market_news` / `f10.channel_news` / `f10.news_channels` 经通用 RPC 自动暴露。
- **文档**：新增 `docs/methods/F10-市场资讯.md`（频道表 / 字段 / 示例）。

## 修复内容

- 本版为新增市场资讯模块，未改动 7709 行情、扩展行情、离线行情等既有能力，无行为性修复。

## 升级

```bash
python -m pip install --upgrade "eltdx==3.4.8"
```

> 说明：市场资讯为全市场资讯流（非个股维度），与个股 F10「公司资讯 / 研报」互补。
