组合示例：

```python
from eltdx.mac import FieldBit, PresetField, build_bitmap

fields = PresetField.BASIC + FieldBit.AMOUNT + FieldBit.MAIN_NET_AMOUNT

```

## 板块代码转换

| 输入 | 请求编号规则 |
| --- | --- |
| USxxxx | 30000 + 数字部分 |
| HKxxxx | 20000 + 数字部分 |
| 000xxx | 31000 + 数字部分 |
| 399xxx | 30000 + (原码 - 399000) |
| 899xxx | 32000 + (原码 - 899000) |
| 88xxxx | 20000 + (原码 - 880000) |
| 其他 | 直接 int(原码) |

Fields 类型接受 FieldBit、PresetField、FieldSelection 或 Iterable[FieldBit]。FieldSelection 用 + / | 组合并按首次出现顺序去重。build_bitmap(fields, *, width=20) 返回 bytearray；width 为 1..20 字节，超宽字段抛 ValueError。字段描述来自 A 股/MAC 原始定义，扩展市场仍需按品种核实单位。

这是 convert_board_code 的实际规则，不按板块名称猜映射。上述显示码与 Category 中的分类码不同。
